# ONNX Runtime provider selection
#
# ONNX Runtime package variants are mutually exclusive because every variant
# installs the same ``onnxruntime`` Python module. Installing all variants into
# one environment does not combine providers; the last package installed wins.

# DarkFusion's tested Windows default:
onnxruntime-directml==1.22.0; platform_system == "Windows"

# Non-Windows fallback:
onnxruntime>=1.17.0; platform_system != "Windows"

# To deliberately change providers, replace the DirectML line above with one
# of these rather than installing it alongside DirectML:
# onnxruntime-gpu==1.22.0       # NVIDIA CUDA + TensorRT
# onnxruntime-openvino>=1.17.0  # OpenVINO
