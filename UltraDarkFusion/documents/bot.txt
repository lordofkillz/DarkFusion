Q: What is UltraDarkFusion?
A: UltraDarkFusion is a graphical interface tool for object detection, dataset management, and image annotation using PyQt. It supports models like YOLO, allows you to edit and generate annotations, and can even help train your own models.

Q: What are the main features of UltraDarkFusion?
A: It supports object detection on images and videos, video frame extraction, dataset manipulation, easy annotation tools, automated annotation, dataset statistics and analysis, model conversion (PyTorch, ONNX, CoreML), and full training routines for YOLO and Ultralytics.

Q: What do I need to install to use UltraDarkFusion?
A: You need Python 3.6+, PyQt5, Numpy, OpenCV, PyTorch, Ultralytics YOLO, Darknet, scikit-image, and matplotlib. For training, you’ll want a CUDA-enabled GPU and the Darknet framework too.

Q: How do I install UltraDarkFusion?
A: First, clone the repository with `git clone https://github.com/<username>/UltraDarkFusion`.
Then, run `pip install -r requirements.txt` inside the folder.
Download any pretrained model weights you need (like YOLOv3 or YOLOv5), and run the app with `python UltraDarkFusion.py`.

Q: How do I run object detection on an image?
A: Open the app, go to File > Open Image, pick your image.
Then Model > Load Model and choose your YOLO weights.
Hit Model > Detect to run detection! You can tweak confidence or NMS threshold for better results.

Q: How do I process a video?
A: Extract frames using the video tools, then run detection in batch on the extracted images. You can annotate, filter, and save results frame by frame.

Q: How can I manage my dataset in UltraDarkFusion?
A: Load your dataset via View > Load Dataset. You can filter images by class, move/copy images and labels, right-click to delete a label, and bulk clear or move images by class from the sidebar.

Q: How do I annotate images manually?
A: Load a dataset, open an image, and use the toolbar to draw bounding boxes or polygons.
Pick the class from the dropdown, and save the annotation. You can always load and edit existing annotations later.

Q: Can I auto-annotate images?
A: Yes! Just load a detection model, run inference, and the tool can auto-generate bounding boxes or segmentations for you. You can review and edit these before saving.

Q: How do I train a custom model?
A: Prepare your dataset and labels. Use Data > Output to generate .txt files. Then go to Model > Train, select your config/data/weights, and start training.
Training logs and stats will show up live. Trained weights are saved when finished.

Q: What models are supported?
A: Any YOLO model (YOLOv3, YOLOv5, YOLOv8, etc.), plus you can use models exported to ONNX or CoreML for deployment.

Q: Can I convert my model to ONNX or CoreML?
A: Yes, UltraDarkFusion has built-in tools to convert between PyTorch, ONNX, and CoreML formats from the Tools menu.

Q: What does the “Adjust labels to fit” option do?

Q: What is shadow augmentation?
A: Shadow aug adds synthetic shadows to objects in your images to make your model more robust to lighting changes.

Q: What does “remove noise aug” do?
A: It removes small, spurious pixels or blobs from inside your segmentation masks, making your labels cleaner.

Q: What is the “copy and paste” augmentation?
A: This copies labeled objects and pastes them into new locations or backgrounds, boosting dataset variety without manual effort.

Q: How do I create my training files in UltraDarkFusion?
A: Go to the “Create Files” tab, then click “Create Train Files.”
- Select the folder with your images and .txt label files.
- The tool will generate a `train.txt` file (with paths to images), plus `obj.data`, `obj.names`, and a backup folder.

Q: What files do I need for training with YOLO/Darknet?
A: You’ll need:
- `train.txt`: List of your training images
- `obj.data`: Paths to datasets and where to save weights
- `obj.names`: Class labels
- A backup folder (for weights)

Q: How do I edit my model configuration (cfg) file?
A: Go to the “cfg Edit” tab and select your configuration file.
- Set the batch size (number of images per batch)
- Set subdivisions (should not exceed batch size)
- Set width and height (match to your image size for best results)
- Set `max_batches` (at least 2,000 times the number of classes)
- Set the number of classes to match your dataset

Q: What do batch and subdivisions mean in the config file?
A: `batch` is how many images are processed at once. `subdivisions` splits that batch for memory efficiency—should never be larger than `batch`.

Q: How do I start training my model?
A: Go to the “Darknet Training” tab.
- Select your `obj.data` file, the edited `.cfg` file, and pre-trained weights (like `tiny-yolov4.weights`)
- If training from scratch, check “clear_weights”
- Click “train” to start. Progress appears in the terminal and as `chart.png` in your directory.

Q: Where are my trained weights saved?
A: All saved weights are stored in the backup folder you chose when creating your training files.

Q: How do I test my trained model?
A: Use the `.cfg` file and weights you trained to perform inference (object detection) tests directly from the app or with your own scripts.

Q: Can I monitor training progress visually?
A: Yes! Progress appears in the terminal and you can view loss and accuracy curves in `chart.png` inside your UltraDarkFusion directory.

Q: What should I do if I want to train from scratch, not use pre-trained weights?
A: In the “Darknet Training” tab, select “clear_weights” before starting training to initialize from scratch.

Q: Do I need to save my config under a new name after editing?
A: If you’ve changed any important settings (batch size, classes, etc.), save your `.cfg` with a new name to keep your edits separate from the original file.
